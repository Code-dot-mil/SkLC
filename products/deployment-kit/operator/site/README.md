# Deployment site

This Operator Astro site serves skill instructions, adjudication, and original scanner evidence. Its catalog supports text search, categories, tags, recommendation filters, and sorting. Safety labels come only from completed adjudication.

Install dependencies with `npm ci`. Set `SKILL_EXCHANGE_GENERATED_ROOT` to the absolute path of generated site data before running `npm run build` or `npm run dev`. Generation is a separate Operator CLI step; the Node build consumes its output. Run `npm run lint` and `npm test` to validate site changes.

The generated `index.json` supplies each skill's adjudication summary, status, coverage judgment, dispositions, and scope, alongside skill content and catalog metadata. Native run/finding/artifact rows preserve the original scanner display; paired false positives are annotated by ordered index and rule identity. The assessment page presents one current scan through Summary and Findings. The trust snapshot leads with the recommendation, AI review outcome, and review scope. Summary keeps the outcome, limitations, and scan date visible; scanner metadata, the full adjudication summary, and report downloads are available under Advanced details. Confirmed and unresolved findings appear first and start expanded; false positives start collapsed. Labels and review reasons come from the existing adjudication report, while scanner explanations and remediation remain identified as scanner evidence. Summary displays confirmed and unresolved counts separately, and package ownership stays outside the assessment. The severity filter remains shareable through the URL. Regenerate site data with the matching Operator version before building: each finding must include its determination and adjudication reason. `assessment_downloads.skillspector` and `assessment_downloads.adjudication` supply the two original report downloads. JSON reports live under `assessments/<skill>/` and skill archives under `zips/`; the site copies these to relative public download paths for root or nested hosting.

Consumers who customize this directory own the entire site component, including its future updates.
