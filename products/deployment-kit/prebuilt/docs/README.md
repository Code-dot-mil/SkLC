# SkLC Prebuilt Deployment Kit

This package contains a built Skill Exchange site that can be deployed without building the site or running assessment tools.

Choose a hosting path:

- For GitLab Pages, follow [Install the package](docs/install.md) and then [Deploy with GitLab Pages](docs/deploy-gitlab-pages.md).
- For another web server or static hosting service, follow [Install the package](docs/install.md) and then [Deploy to another static host](docs/deploy-static-hosting.md).

The files under `public/` are the complete static site. Keep their directory structure unchanged so the pages, assets, and skill downloads remain connected.
